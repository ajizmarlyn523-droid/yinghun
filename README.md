# 英魂 · 在线对战测试版

这是原创回合制角色扮演游戏《英魂》的轻量在线对战版本，用来先验证 1v1 联机、角色选择、猜拳抢行动权和基础技能流程。

## 当前功能

- 1v1 在线房间
- 创建房间 / 加入房间
- 玩家选择角色并准备
- 石头 / 剪刀 / 布抢行动权
- 普攻、技能一、技能二、结束小回合
- Python 本地中转服务器
- 支持同一 Wi-Fi 局域网联机

## 已加入角色

- 神剑：剑诀连胜爆发
- 神刀：越打越强，造成伤害后成长并恢复
- 影子：影遁规避，破命爆发
- 蘑菇术士：孢子成长与轻量复活
- 剑圣：装备剑，破空斩
- 卡牌：红牌、黄牌、蓝牌、紫牌轮换

## 运行方法

### Windows

双击运行：

```bat
start_server.bat
```

然后房主浏览器打开：

```text
http://127.0.0.1:8000
```

同一 Wi-Fi 下，朋友打开：

```text
http://房主电脑IP:8000
```

例如：

```text
http://192.168.1.23:8000
```

### 命令行

```bash
python server.py
```

然后浏览器打开：

```text
http://127.0.0.1:8000
```

## 联机说明

如果朋友进不来，优先检查：

1. 两台设备是否在同一个 Wi-Fi。
2. Windows 防火墙是否允许 Python 访问专用网络。
3. 朋友打开的地址是否是房主电脑的局域网 IP。
4. 如果不是同一网络，需要部署到云服务器，或使用内网穿透。
